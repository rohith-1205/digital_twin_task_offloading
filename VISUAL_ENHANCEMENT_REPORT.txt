VISUAL DESIGN AND CONTROLS
Four textured monocrystalline panels on galvanized supports, weather-driven
soft cloud sprites and time/irradiance-driven sunlight, cabinet, IP65
ESP32 housing with transparent service lid, gateway mast, open-door prefab
shelter with detailed rack and exterior AC, service lighting, gravel,
concrete walkway, and protected conduit routes. PBR materials, soft shadows,
tone mapping, configurable quality and instanced stones are included.
Isometric, front, rear, left, right, top and five equipment focus views are
in the camera selector. Free 360°, reset, Follow signal, presentation tour,
mouse orbit/pan/zoom and clickable equipment inspection are supported.
The currently recorded OFFLOAD path animates through ESP32, gateway and rack;
LOCAL remains in the ESP32 enclosure. Follow signal replays the current row's
visual animation and moves the camera through the scene. Presentation tours
only the current recorded task and equipment. These actions do not advance
or change simulated time, stored rows, decisions or outcomes.

LIMITS
The source's 38-column dataset exports Decision and expected times, but no
Task_Outcome, transmission failure, rejection, or deadline expiry field. The
scene therefore labels results as modeled and states 'Outcome not exported';
it does not invent completion, failure or success. The gateway-to-server visual
link represents the modeled path without asserting its physical medium.
Actual WebGL/browser-console, real pointer, GPU frame-rate and full Streamlit
integration checks were not completed. The only available Chromium binary
crashed before loading a page. The scripted test does not establish finished
visual fidelity; review it in your browser on your demonstration laptop.
No third-party photoreal GLB asset was supplied; locally created textures and
procedural detail improve realism, but photo-quality identity with an unseen
reference photo cannot be certified. Optional GLB loader and procedural
fallback remain available, with model-loading progress and fallback handling.

RUN
Extract the complete ZIP, then in the 'digital twin' folder:
  pip install -r requirements.txt
  streamlit run streamlit_app.py
For historical replay in the standalone viewer:
  python -m http.server 8000
  open http://localhost:8000 and select 3D Twin.
Use the camera selector and the current row's Follow signal button for
OFFLOAD. Step to a LOCAL row to see processing stay in the ESP32.
The existing python digital_twin_simulator.py command would regenerate
historical outputs; it is unnecessary for viewing this included dataset.
