# Renewable-Aware IoT Task Offloading Digital Twin

This repository contains the codebase and simulation data for a **Diagnosed & Validated Renewable-Aware IoT Task Offloading Digital Twin Engine**. It provides a physically grounded simulation architecture and multiple interactive visualization platforms (Streamlit & Vanilla Web) for an Industrial IoT environment.

## Overview

The core problem addressed by this project is deciding whether an IoT edge device (like an ESP32) should execute tasks locally or offload them to an Edge Server, based on the availability of renewable energy (solar/wind), battery state, device CPU load, network latency, and edge server load.

The Digital Twin models six interconnected modules:
1. **Renewable Availability Module**: Simulates solar irradiance and wind power generation.
2. **Battery Module**: Models charge/discharge dynamics, battery state of charge (SoC), and safe thresholds.
3. **ESP32 Device Module**: Generates tasks and reports CPU load, memory, and power draw.
4. **WiFi Network Module**: Simulates network latency, bandwidth, and RSSI with shadow fading models.
5. **Edge Server Module**: Models edge queue depth and execution delays using an M/M/1 queue model.
6. **Decision Engine**: Aggregates telemetry to compute a weighted offloading score to enforce renewable-aware policy thresholds (execute `LOCAL` vs. `OFFLOAD`).

## Repository Contents

### 1. Core Simulation Engine
- **`digital_twin_simulator.py`**: A Python-based simulation engine that models the physical system (solar panel specs, battery depletion penalty, AR(1) task memory continuity, network path loss). Running this file generates a rich dataset (e.g., `simulation_dataset.csv`) tracking all system metrics over time.

### 2. Interactive Dashboards & Visualization
The project features two distinct interactive interfaces for exploring the digital twin:

#### Streamlit Dashboard with 3D Render
- **`streamlit_app.py`**: A comprehensive Streamlit dashboard providing real-time system telemetry and an embedded **High-Fidelity 3D Industrial Digital Twin Viewport** (built with Three.js).
  - Features real-time KPI metrics.
  - Interactive 3D webGL scene showing the Solar Panel Array, Battery Storage System (BESS), ESP32 Edge Node, and Telecom Tower Gateway.
  - Start/Pause/Reset controls for the twin engine.

#### Web Application Architecture Viewer
- **`index.html`**, **`app.js`**, **`style.css`**: A front-end web application showcasing:
  - **System Architecture**: Interactive SVG diagram showing data flow between the 6 core modules.
  - **Data Flow**: A sequence diagram of real-time module exchanges and decision making.
  - **Modules**: Detailed specifications and physical roles for each simulated component.
  
### 3. Datasets
- **`simulation_dataset.csv`**: Baseline simulation dataset generated by the engine.
- **`digital_twin_dataset.csv`** & **`research_digital_twin_dataset.csv`**: Extended simulation datasets for further analysis.

## Getting Started

### Running the Python Simulation
```bash
python digital_twin_simulator.py
```
This will run a 7-day simulation (by default) and output the results to `simulation_dataset.csv`.

### Running the Streamlit Dashboard
Requirements: `streamlit`, `pandas`, `numpy`, `plotly`
```bash
streamlit run streamlit_app.py
```

### Viewing the Web Architecture App
Simply open `index.html` in any modern web browser to interact with the architecture diagrams and data flow visualization.
